# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for InsightFlow.

## Template

See `TEMPLATE.md` for the standard ADR format.

## Index

| ADR | Title | Status | Date |
|-----|-------|--------|------|
| ADR-000 | Architecture Freeze — Foundational Decisions | Accepted | 2026-08-04 |

ADRs are created when:
- A frozen architecture rule must be violated
- A significant technology choice is made
- The architecture changes in a way that affects multiple modules

## How to Create an ADR

1. Copy `TEMPLATE.md` to `ADR-XXX-title-with-dashes.md`
2. Fill in all sections
3. Submit as a PR with the `adr` label
4. Requires approval from System Architect + Tech Lead
5. Merge and update the index above
